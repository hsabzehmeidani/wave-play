# 🎵 WavePlay – Modern Music Player

WavePlay is a feature‑rich, responsive music player that runs entirely in your browser. It combines a clean interface with powerful playlist management and a real‑time audio visualizer – no server required.

## Key Features

- **Full Playback Controls** – Play, pause, prev/next, seekable progress bar, volume slider
- **Playlist Management** – Add/delete tracks, batch select, batch delete, batch play, shuffle selected songs, reset order
- **Playback Modes** – Shuffle (global), Repeat (off/all/one), Play All
- **Real-time Visualizer** – Frequency bars using Web Audio API
- **Responsive UI** – Desktop / Mobile
- **Persistent Storage** – Saves playlist, current track, repeat/shuffle state to localStorage
- **Modern Aesthetics** – Glassmorphism, gradient accents, smooth transitions, dark theme

## Tech Stack

- HTML5 / CSS3 (TailwindCSS for rapid styling)
- Vanilla JavaScript (ES6+)
- Web Audio API (analyser node for visualizer)
- Font Awesome 6 (icons)
- LocalStorage API
